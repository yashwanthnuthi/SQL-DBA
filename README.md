# SQL Server DBA | Engineering Portfolio

A growing portfolio of Microsoft SQL Server administration, performance tuning, high availability, automation, and production troubleshooting.

> **Portfolio status:** In development. Catalog entries tagged **Planned** are not implemented or validated.

## Focus areas
- SQL Server 2022 administration and diagnostics
- Query performance, wait statistics, blocking, deadlocks, and indexing
- Always On availability groups, Windows Server failover clustering, and disaster recovery
- SQL Server replication, backups, restore, and security
- PowerShell and T-SQL automation
- Incident response and root cause analysis

## Evidence standard
Each completed entry should include its purpose, supported versions, prerequisites, permissions required, safety considerations, how to run it, expected output, sample output (sanitized), and validation/testing status.

**Security:** Never upload passwords, connection strings containing secrets, tokens, customer data, or unredacted production screenshots.
